# StyleNest - E-commerce Backend

A scalable and production-ready eCommerce backend built with Node.js, Express.js, and MongoDB. It provides secure authentication, product management, order processing, payment integration, image uploads, and role-based access control through RESTful APIs.

## Features

- JWT Authentication & Authorization
- Role-Based Access Control (Admin/User)
- User Registration & Login
- Product CRUD Operations
- Category & Brand Management
- Image Upload with Cloudinary
- Shopping Cart Management
- Wishlist Support
- Order Management
- Payment Gateway Integration (Razorpay)
- Product Reviews & Ratings
- Coupon & Discount Support
- Inventory Management
- Search, Filter, Sorting & Pagination
- Secure Password Hashing with bcrypt
- Error Handling Middleware
- RESTful API Architecture
